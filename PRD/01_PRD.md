## 1. 제품 개요

### 한 줄 요약
자녀의 로블록스 게임 시간을 부모가 설정하고, 자녀 스스로 약속을 지키도록 돕는 Electron 타이머 앱. 로컬 웹 대시보드는 Phase 2 이후 확장 범위입니다.

### 해결하는 문제
"30분만 하기로 했는데 왜 아직도 하고 있어?"라는 반복되는 말다툼.
약속한 게임 시간을 자녀가 지키지 않는 문제를 시각적 타이머와 경고 알림으로 구조화하고, 시간 만료 시 로블록스를 자동으로 종료한다.

### 핵심 가치
- 말로 협상하는 대신 앱이 약속을 집행한다
- 자녀 스스로 "내가 정한 약속"임을 느끼게 한다 (앱 이름: My Pact)
- 부모는 현재 Electron 설정/관리자 화면으로 시간을 관리하고, 추후 통계 대시보드로 실제 플레이 시간을 확인한다

## 2. 사용자

### 주요 사용자

| 역할 | 누구 | 상황 | 목표 |
|------|------|------|------|
| 부모 | 자녀의 게임 시간을 관리하고 싶은 부모 | 하루 한 번 설정 화면에서 허용 시간 조정 | 약속한 시간이 자동으로 지켜지길 원함 |
| 자녀 | 로블록스를 즐기는 초등학생 | 로블록스 실행 또는 앱 타이머 시작 | 오늘 남은 세션과 시간을 확인 후 게임 |

### 사용자 시나리오

**시나리오 A — 평일 게임 세션**
1. 자녀가 학교 숙제를 마치고 로블록스를 실행한다
2. 앱이 Roblox 프로세스를 감지하고 오늘 남은 세션/잔여 시간을 확인한다
3. 카운트다운이 시작되고, 5분·3분·1분·30초 전에 경고 팝업이 뜨며 10초부터 중앙 카운트다운을 표시한다
4. 시간이 만료되면 앱이 로블록스 프로세스를 종료하고 세션을 기록한다

**시나리오 B — 부모 설정 관리**
1. 부모가 앱 설정/관리자 패널을 PIN으로 연다
2. 허용 시간, 세션 횟수, 가능 시간대를 조정한다
3. 저장된 설정이 부모/자녀 계정에서 동일하게 적용된다

| 요일별 세부 설정 UI | 요일별 개별 시간 설정 전용 UI | P3 | 간단 |

┌─────────────────────────────┐
│          My Pact            │
│                             │
│   오늘 남은 시간             │
│      [ 00:28:45 ]           │
│                             │
│     [▶ 게임 시작]            │
│                             │
│  평일 30분 · 오후 4시 이후   │
└─────────────────────────────┘
```

**경고 팝업 (게임 중)**
```
┌─────────────────────────────┐
│  ⚠️  5분 남았어!             │
│  약속 기억하지? My Pact!    │
└─────────────────────────────┘
(4초 후 자동으로 코너 위치로 복귀)
```

주말 허용 시간: [60] 분 × [1] 회
게임 시작 가능: [16:00] 이후
게임 종료 시각: [21:00] 이전
[저장]
```

## 5. 사용자 흐름 (User Flow)

### 핵심 흐름 — 게임 세션
```
Roblox 실행 감지 또는 앱 열기 → 오늘 남은 세션/잔여 시간 확인 → 타이머 시작
→ 카운트다운 시작 → 경고 팝업(5분/3분/1분/30초) → 10초 중앙 카운트다운
→ 시간 만료 → Roblox 프로세스 종료 → 세션 JSON 기록
```

### 시간대 제한 흐름
```
앱 열기 → 시작 가능 시간 전이면 → "오후 4시 이후에 시작할 수 있어요" 표시
→ 허용 시간대 도달 → [시작] 버튼 활성화
```

## 7. 안 만드는 것 (Out of Scope)

> 이 목록에 있는 건 Phase 1~2에서 만들지 않습니다.

- 로그인 / 회원가입 — 이유: 가족 1대 PC에서만 사용, 불필요한 복잡성
- 클라우드 DB / 서버 백엔드 — 이유: 로컬 JSON으로 충분
- 다중 자녀 프로필 — 이유: 단일 프로필로 MVP 완성 우선
- iOS / Android 앱 — 이유: Electron 데스크탑 우선
- Vercel 외부 배포 — 이유: 로컬 사용 완성 후 나중에 검토
- 결제 / 구독 — 이유: 개인 가족용 도구
